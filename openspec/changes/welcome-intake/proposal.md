# Proposal

## Why

Анкеты `/welcome` (новый гость) и `/welcome/back` (повторный визит) готовят визит: напиток, парковку, формат общения и — главное — противопоказания с флагами безопасности для мастера. Их нужно перенести на landing_v2 вместе с `/api/welcome`, исправив найденные ошибки: повторная анкета не отправляется без телефона в ссылке, изменения здоровья не доходят до мастера, подписи молока неверны.

## What Changes

- `/welcome`: мастер из 8 экранов (приветствие, 6 шагов, «спасибо») с обращением на «ты»/«вы», маской телефона, подстановкой `?name=` и `?phone=`.
- `/welcome/back`: мастер из 5 экранов (приветствие, здоровье, напиток, пожелания + согласие, «спасибо»).
- `POST /api/welcome` в Express с rate limit, honeypot, валидацией и отправкой через общий модуль `staff-notifications`.
- Обе страницы — без каркаса сайта, `noindex`, в стиле ДС v2 (Chip, YesNo, Checkbox, TextField из `design-system`).

Переносится без изменений: шаги, поля, обязательность и зависимые вопросы (молоко для капучино/американо/матчи, сахар и сливки для кофе, номер машины, возраст и нужды ребёнка), списки опций (напитки, молоко, нужды ребёнка, источники, 9 противопоказаний), взаимоисключающее «Ничего из перечисленного», критические противопоказания и блок «⚠️ ФЛАГИ БЕЗОПАСНОСТИ», формат письма и Telegram, контракт API и коды ответов, rate limit 3/мин, цели `welcome_started`, `welcome_step_2` … `welcome_step_6`, `welcome_submitted`.

Меняется / исправляется:
- `/welcome/back` без `phone` в ссылке показывает поля «Имя» и «Телефон» вместо гарантированной ошибки 422.
- «Здоровье изменилось» и комментарий о здоровье повторного гостя попадают в письмо и Telegram (сейчас теряются).
- Подписи молока полные и верные: Обычное, Кокосовое, Банановое, Миндальное, Фисташковое, Без молока (сейчас «Кокосовое (Banana)», банановое и миндальное приходят сырым id).
- Поле-ловушка для ботов действительно присутствует в разметке (сейчас клиент всегда шлёт пустое значение).
- Ссылка Telegram на экране «спасибо» ведёт на аккаунт студии из настроек сайта (сейчас — на номер телефона); MAX показывается, только если задан.
- Варианты напитков — без эмодзи, в стиле ДС.

## Capabilities

### New Capabilities
- `guest-intake-forms`: анкеты нового и повторного гостя — шаги, поля, зависимости, валидация, обращение «ты/вы», экран «спасибо», цели.
- `welcome-api`: HTTP-контракт `POST /api/welcome` и формат уведомления об анкете.

### Modified Capabilities
(нет; уведомления используют `staff-notifications` из `booking-pipeline` без изменения его требований)

## Impact

- Новые файлы: `src/pages/welcome.ts`, `welcome-back.ts`, `src/content/welcome-options.ts` (опции + подписи — один источник для формы и уведомлений), `src/client/welcome.client.ts`, `server/api/welcome.ts`, `server/lib/notify/format-welcome.ts`.
- Зависит от `bootstrap-platform`, `design-system`, `booking-pipeline` (notify, rate-limit, phone).
- Ссылки на анкеты рассылаются гостям вручную — URL и query-параметры сохраняются.
