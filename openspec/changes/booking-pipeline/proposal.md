# Proposal

## Why

Заявка на запись — главная конверсия сайта. Сейчас это мастер из трёх шагов без маски телефона, а `/api/lead` не защищён от спама и при сбое почты теряет заявку, даже если Telegram доступен. Макет v2 предлагает один экран; landing_v2 переносит запись на него и делает доставку заявок надёжнее.

## What Changes

- Форма записи на одном экране: Имя, Телефон (с маской), Услуга, необязательное «Удобное время», «Способ связи», галочка акции первого визита, согласие с политикой. Один и тот же компонент работает в диалоге (кнопки «Записаться» по всему сайту) и встроенным в секцию «Контакты».
- Режим сертификата: при услуге «Подарочный сертификат» заголовок «Оформление сертификата», поля времени и акции скрыты.
- `POST /api/lead` в Express с валидацией телефона, honeypot и ограничением частоты запросов.
- Общий модуль уведомлений персонала (email через SMTP Timeweb + Telegram), который переиспользует `welcome-intake`.

Переносится без изменений: список услуг формы (11 пунктов), способы связи (Звонок / Telegram / WhatsApp / MAX), поля тела запроса (`name, phone, service, time, contact_method, promo, utm_*`), сбор UTM, SMTP `smtp.timeweb.ru` с перебором портов 587 → 465 → 2525, формат и эмодзи писем и сообщений Telegram, цели `form_submit`, `click_phone`, `click_telegram`.

Меняется:
- **BREAKING (UX)**: три шага → один экран. Слоты времени «Утро / День / Вечер» приводятся к часам работы (10–13, 13–17, 17–21), выбор даты убирается; время необязательно.
- Телефон проверяется (11 цифр, российский номер) на клиенте и сервере; раньше принимался любой непустой.
- В `/api/lead` добавляются honeypot и ограничение 5 запросов в минуту с IP.
- Email и Telegram отправляются параллельно; заявка считается принятой, если доставлена хотя бы в один канал (раньше сбой почты = ошибка, даже при рабочем Telegram).
- Пользовательские значения в HTML письма экранируются (раньше не экранировались).
- UTM-метки сохраняются на время сессии, а не только на странице входа.
- Ответы API унифицируются: `{ ok: true }` / `{ ok: false, error }`, тексты ошибок на русском.

## Capabilities

### New Capabilities
- `booking-form`: форма записи на сайте — поля, валидация, режим сертификата, состояния отправки, успеха и ошибки, предвыбор услуги.
- `lead-api`: HTTP-контракт `POST /api/lead` — валидация, защита от спама, коды ответов.
- `staff-notifications`: доставка заявок и анкет персоналу по email и в Telegram, форматы сообщений и отказоустойчивость.

### Modified Capabilities
(нет)

## Impact

- Клиент: `src/ds/patterns/booking-form/*`, обработчик `[data-booking]`, `src/client/utm.ts`, `src/client/phone-mask.ts` (общий с анкетой).
- Сервер: `server/api/lead.ts`, `server/lib/notify/{email,telegram,format-lead}.ts`, `server/lib/{rate-limit,validation,html-escape,retry,timeout}.ts`.
- Зависимость: `nodemailer`.
- Переменные окружения: `SMTP_USER`, `SMTP_PASS`, `NOTIFY_EMAIL`, `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`.
- Заглушки `href="#contacts"` из `home-page` заменяются на открытие диалога.
