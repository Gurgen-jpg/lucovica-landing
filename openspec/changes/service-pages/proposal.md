# Proposal

## Why

Страницы услуг (`/laser-epil`, `/sugaring`, `/electro-epil`, `/complex`, `/cert`) собирают поисковый трафик по коммерческим запросам «… в Ростове-на-Дону». В макете v2 их нет, но они должны перейти на новую дизайн-систему вместе с главной, сохранив контент, URL, метаданные и цели — и избавившись от расхождений цен с прайсом.

## What Changes

- Общий шаблон страницы услуги из секций ДС: хлебные крошки → Hero → тематические секции → Цены → Отзывы → FAQ → финальный CTA.
- `/laser-epil`: Hero, «Почему лазер» (сравнение 4 методов), «Как проходит» (5 шагов), Зоны (12 женских / 10 мужских, клик открывает запись с зоной), «Аппарат» (диодный 808 нм), «Кому подходит / Противопоказания», «Результат» (4 показателя), Отзывы, Цены (4 категории), FAQ (8), CTA.
- `/sugaring`: та же структура; «Состав пасты» вместо «Аппарата»; зоны без кликов; цены — 4 категории шугаринга.
- `/electro-epil`: «Когда лазер не справляется» (ссылка на `/laser-epil`), «Для каких задач», «Метод», цены — 4 тарифа по времени.
- `/complex`: Hero «Выгода до 30%», таблицы женских и мужских комплексов, CTA.
- `/cert`: Hero, 4 номинала с описаниями, CTA с записью в режиме сертификата.

Переносится без изменений: URL, тексты секций, FAQ и отзывы каждой страницы, цели (`laser_epil_cta_click`, `laser_epil_phone_click`, `laser_epil_zone_click`, `sugaring_cta_click`, `sugaring_phone_click`, `electro_epil_cta_click`, `electro_epil_phone_click`, `complex_cta_click`, `cert_cta_click`, `complex_page_view`, `cert_page_view`), description страниц, JSON-LD `Service` + `FAQPage` + `BreadcrumbList`, предвыбор акции из Hero/CTA лазера.

Меняется / исправляется:
- Цены на зонах лазера берутся из прайса (`services.ts`), а не захардкожены (сейчас расходятся: например, мужские ноги 4 990 против 5 990 в прайсе). Зона без позиции в прайсе показывается без цены.
- Запись по зоне передаёт услугу из списка формы + зону как уточнение (сейчас уходит строка, которой нет в списке).
- Title без двойного бренда: «Шугаринг в Ростове-на-Дону — студия LUCOVICA» вместо «… — студия Lucovica | LUCOVICA».
- У `/complex` и `/cert` появляются свои Open Graph и JSON-LD `Service` (сейчас только хлебные крошки).
- Заглушка «Фото до/после» в «Результате» убирается до появления реальных фото.
- В «Цены» на страницах услуг у каждой категории и позиции — кнопка записи с правильной услугой формы.

## Capabilities

### New Capabilities
- `service-pages`: общая структура, навигация, цены, запись, метаданные и аналитика страниц услуг, а также специфичный контент каждой из пяти страниц.

### Modified Capabilities
(нет)

## Impact

- Новые файлы: `src/pages/{laser-epil,sugaring,electro-epil,complex,cert}.ts`, секции `src/sections/service/*` (общие: breadcrumb, hero, steps, comparison, zones, checklist, results, cta), контент `src/content/pages/<slug>/*.ts` (тексты, FAQ, отзывы, зоны).
- Переиспользует из `home-page`: секции цен, отзывов, FAQ; из `booking-pipeline`: кнопки записи с уточнением.
- Источник текстов: `../landing/src/components/{laser-epil,sugaring,electro-epil,complex,cert}/*`.
