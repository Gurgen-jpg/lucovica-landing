# Design

## Context

Макет: `../LUCOVICA — Design System 2.0.html`, борды 06 (десктоп 1440) и 07 (мобильный 390). Данные: `../landing/src/lib/services-data.ts`, `../landing/src/components/FAQ.tsx`, `Reviews.tsx`, `About.tsx`, `src/app/privacy/page.tsx`. Решение «структура макета, данные сайта» — см. proposal.md.

## Goals / Non-Goals

**Goals:**
- Контент — в `src/content/*` (типизированные данные), секции — чистые функции от данных.
- Одна модель цен для главной, страниц услуг, формы записи и JSON-LD.

**Non-Goals:**
- Подменю в навигации (NavigationMenu из борда 04 упрощаем до плоского списка).
- Встроенная карта Яндекса.

## Decisions

### D1. Модель цен `src/content/services.ts`
Переносим `SERVICES`, `ELECTRO_PRICES`, `CERTIFICATES` как есть, добавляем к категории поля `group: 'laser' | 'sugaring' | 'complex' | 'electro'`, `audience` (подпись подгруппы: «Девушки», «Мужчины», «Мастер Екатерина (руководитель)», «Юные леди (до 15 лет)») и `bookingService` — точное значение из списка услуг формы. Вкладки главной строятся фильтром по `group`; «от N ₽» карточек — `min(price)` по группе (для сертификата — минимальный номинал). Этим закрывается расхождение «`defaultService` не из списка формы».

### D2. Секции — функции `(data) => html`
`src/sections/home/hero.ts`, `numbers.ts`, `philosophy.ts`, `services.ts`, `prices.ts`, `ritual.ts`, `masters.ts`, `reviews.ts`, `faq.ts`, `contacts.ts`. Каждая собирается только из примитивов ДС (`SectionHeader`, `Button`, `Tabs`, `Accordion`, `Carousel`, `Photo`). Секции услуг/FAQ/отзывов позже переиспользуются страницами услуг с другими данными.

### D3. Кнопки записи — декларативные
Любая кнопка записи — `<button data-booking data-service="Электроэпиляция" data-goal="…">`. Обработчик из `booking-pipeline` делегирован на `document` и открывает диалог с предвыбором. До применения `booking-pipeline` шаблон кнопки выводит ссылку на `#contacts` — главная работоспособна в любом порядке применения.

### D4. Якоря-алиасы
Секции получают id по макету; для старых якорей — пустые `<span id="pricing" class="anchor">` в начале соответствующих секций (с `scroll-margin-top` под высоту хедера). Без JS-редиректов.

### D5. Хедер
`position: sticky; top: 0`, фон `--lv-bg`, нижняя линия 1px. Сетка макета: навигация слева, логотип по центру, телефон и «Записаться» справа. Ниже 768px — логотип слева, «Записаться» (size 2) и кнопка меню справа; меню — примитив Dialog в варианте боковой панели (тот же фокус-трап и Escape).

### D6. Плавающие кнопки
`IntersectionObserver` на сторожевом элементе на 400px и на `#contacts` вместо обработчика `scroll` — без работы на каждом кадре. Без анимации пульсации (противоречит «тишине» ДС).

### D7. Политика конфиденциальности
Текст переносится в `src/content/privacy.ts` как массив разделов; дата обновления — константа там же. Каркас — упрощённый хедер (логотип + «← На главную») без промо-плашки и плавающих кнопок, как сейчас.

## Risks / Trade-offs

- [Смена h1 с «Студия лазерной эпиляции и шугаринга» на «Лазерная эпиляция и шугаринг» может повлиять на ранжирование] → title и description не меняются; h1 сохраняет ключевые слова «лазерная эпиляция» и «шугаринг».
- [Полные списки цен во вкладках длиннее, чем 6 строк макета] → вкладка с подгруппами; на десктопе две колонки для вкладок с 2+ подгруппами.
- [Без iframe карты посетитель не видит карту на странице] → ссылка «Построить маршрут» открывает Яндекс Карты с организацией; Метрика покажет, нужен ли iframe.
