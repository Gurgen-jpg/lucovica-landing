# Spec Delta

## Purpose

Публикует политику обработки персональных данных LUCOVICA по 152-ФЗ, на которую ссылаются все формы сайта, включая анкету с данными о здоровье.

## ADDED Requirements

### Requirement: Privacy policy page
Страница `/privacy` SHALL содержать 12 разделов текущей политики (общие положения, сведения об операторе, состав данных — включая сведения о здоровье из анкеты, цели, правовые основания, хранение, третьи лица — Яндекс Метрика и Telegram, права субъекта, cookie, защита, изменение политики, контакты), ссылку «← На главную» и дату последнего обновления. Дата MUST задаваться вручную при изменении текста. Контакты оператора MUST браться из настроек сайта. Страница MUST иметь `meta robots` `noindex, nofollow` и не входить в sitemap.

#### Scenario: Fixed update date
- **WHEN** сайт пересобирается в разные дни без изменения текста политики
- **THEN** дата «Последнее обновление» на странице не меняется

#### Scenario: Linked from forms
- **WHEN** посетитель нажимает ссылку «политикой конфиденциальности» в любой форме
- **THEN** открывается `/privacy`
