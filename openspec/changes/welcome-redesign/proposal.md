# Proposal

## Why

Анкета `/welcome` написана в дружеском тоне («Привет, наша звёздочка ✨», обращение на «ты» по умолчанию, женский род). Это не соответствует уровню сервиса студии. Нужна деловая, универсальная анкета, оформленная по ДС 2.0.

## What Changes

- `/welcome` получает новые тексты из `docs/welcome-texts.md` (редакция 2): везде «вы», нейтральный род, без эмодзи.
- Вопрос «На ты / на вы» удаляется. В шаге 1 остаются имя и телефон. Клиент отправляет `address_form: 'vy'`.
- Новый макет по эталону `docs/welcome-mockup.html`:
  - ≥960px: тёмная панель слева с логотипом, заголовком, списком разделов 01–06 и контактами, форма справа;
  - <960px: одна колонка, логотип и счётчик сверху, полоса прогресса;
  - однозначный и множественный выбор — плитки (выбранная залита ониксом); противопоказания — список чекбоксов с разделителями;
  - счётчик «Шаг N из 6»;
  - экран «Спасибо» с тёмной карточкой адреса и часов работы.
- Подписи вариантов меняются (напитки, молоко, сахар/сливки, общение, источник, противопоказания). id вариантов не меняются.

Без изменений: id и имена полей, контракт `POST /api/welcome`, обязательность полей, зависимые вопросы, взаимоисключающий пункт «нет противопоказаний», критические противопоказания и флаги безопасности, подстановка `?name=` и `?phone=`, цели Метрики (`welcome_started`, `welcome_step_2` … `welcome_step_6`, `welcome_submitted`), `noindex`, работа без JS (все шаги одной формой).

`/welcome/back`: использует общий шаблон и CSS, поэтому получает новый макет. Тексты повторной анкеты в этом изменении не меняются — это отдельная задача.

## Capabilities

### Modified Capabilities
- `guest-intake-forms`: убрана форма обращения у новой анкеты, изменены тексты и макет.

## Impact

- `src/sections/welcome/welcome.ts`, `src/styles/welcome.css`, `src/client/welcome.ts`, `src/content/welcome-options.ts` (`formLabel`).
- Подписи в уведомлениях (`label`) решаются отдельно: по умолчанию меняются только `formLabel`, чтобы письма и Telegram остались привычными для администратора.
- Тесты: unit-тесты правил шагов, e2e `e2e/welcome.spec.ts` (сценарий «На вы» удаляется), снапшоты уведомлений не должны меняться.
