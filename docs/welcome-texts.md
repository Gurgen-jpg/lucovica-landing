## Проверка заполнения
- Пока обязательные поля шага не заполнены, кнопка «Далее» неактивна. Отдельных текстов ошибок у групп выбора нет.
- Тексты ошибок есть только у полей: имя, телефон, согласие (см. выше).
- В скрытом поле отправляется `address_form = vy`.
